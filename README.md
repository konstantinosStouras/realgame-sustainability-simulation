## Layout

- `index.html`, `styles.css`: public starter website (no build step).
- `src/`: future supporting code.
- `notes/`: versioned project notes suitable for public sharing.
- `.nojekyll`: serve static files directly through GitHub Pages.

## Updates

Edit files in this project's working directory, review `git diff`, then commit and push to `main`. GitHub Pages publishes from the root of `main`. The project inherits the custom domain of the owner's main GitHub Pages site; do not add a project CNAME file.

For a local preview, run `python -m http.server 8000` here and visit http://localhost:8000.

This repository is public. Do not commit passwords, tokens, private correspondence, student data, or proprietary RealGame teaching materials. The external RealGame service remains separate from this project.
