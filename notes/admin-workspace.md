# Instructor workspace

Instructor sign-in opens session management with setup on the left and collapsible active/past lists on the right. Each panel has a plus/minus control. Company tools appear only for students or an explicit instructor company preview. The account dropdown and shared light/dark theme work across these views.

See [session lifecycle and temporary classrooms](session-lifecycle.md) for the supported Close, Delete and Test actions, student effects, data retention, and the browser-only multi-tab test workflow.
